=========================================================
index.html - minha página principal
=========================================================

Aqui deixei só as partes que tiveram decisão minha. O resto
é HTML padrão.

HEAD
====
<script>
  if (!sessionStorage.getItem('splashExibido')) {
    window.location.replace('loading.html');
  }
</script>

- Na primeira visita não existe a flag "splashExibido", então
  jogo pro loading.html.

- Depois que o loading termina ele seta essa flag no
  sessionStorage, como o sessionStorage é por aba, 
  se a pessoa fechar e abrir a aba aparece o loading de novo.

BODY / ESTRUTURA
================
luzes
- 4 divs .luz que o CSS anima. São barras desfocadas que dão
  aquele fundo "cênico". Só estrutura, o efeito é no style.css.

nav-time-container
- caixinha fixa no canto com o relógio. O id brasilia-clock é
  quem o clock.js atualiza.

card / form
- form#formCep com input#cep e o botão. Percebi que preciso
  do maxlength="9" porque o CEP formatado tem 8 numeros + 1
  hifen (o script formata 99999-999 enquanto digita).
- p#mensagem é onde eu mostro erro/sucesso.

resultado (endereço)
- seção#resultado que começa com class="resultado oculto".
  O "oculto" é display:none; só mostro depois que a API
  respondeu. Cada campo (logradouro, bairro, cidade, estado,
  ddd) tem um id que o script preenche.

CLIMA (a parte que eu caprichei)
================================
div#wf-main-temp
- É o card que mostra temperatura/ícone/descrição.

Dentro dele eu coloquei 5 <video>:
  #wf-temp-video           -> nublado
  #wf-temp-video-chuva     -> chuva leve
  #wf-temp-video-ceu-limpo -> céu limpo
  #wf-temp-video-poucas    -> poucas nuvens
  #wf-temp-video-pancadas  -> pancadas de chuva

- Todos com autoplay muted loop playsinline.
- Muted é obrigatório pra navegador deixar tocar sozinho.
- Os 5 ficam escondidos (display:none no CSS) e o script
  mostra só o certo.
- Decisão: deixei todos os <video> no HTML em vez de criar
  por JS. Vantagem: é simples e já fica "pré-carregado" no
  DOM. Desvantagem: carrega várias fontes de vídeo de cara
  (mais peso no carregamento inicial), mas pra esse caso
  valeu porque é um projeto pequeno.

wf-extra-stats
- 4 cards: temp máx, mín, umidade e vento, cada um com um
  ícone Font Awesome e um id de valor (wf-temp-max, -min,
  -humidity-val, -wind-val).
