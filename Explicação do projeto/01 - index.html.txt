=========================================================
index.html - minha página principal
=========================================================

Aqui eu vou deixar só as partes que tiveram decisão minha. O
resto é HTML padrão que a gente já viu em aula.

HEAD
====
<script>
  if (!sessionStorage.getItem('splashExibido')) {
    window.location.replace('loading.html');
  }
</script>

- Na primeira visita não existe a flag "splashExibido", então
  ele me manda pro loading.html.
- Quando o loading termina, ele seta essa flag no sessionStorage.
  Como o sessionStorage é por aba, se a pessoa fechar e abrir a
  aba de novo, aparece o loading de novo. Eu queria que fosse
  assim mesmo.

CDNs DO MAPA
============
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>

- São os arquivos da biblioteca Leaflet (a que desenha o mapa).
- Vêm de um CDN (servidor público) porque eu não quero baixar e
  versionar uma biblioteca gigante no meu projeto. Só aponto pra
  internet e uso.
- A ordem importa: o CSS do Leaflet entra no <head> e o JS entra
  no final do body, ANTES do meu script.js — porque o meu código
  usa o "L" que o Leaflet define. Se viesse depois, meu script
  quebraria.

BODY / ESTRUTURA
================
luzes
- 4 divs .luz que o CSS anima. São barras desfocadas que dão
  aquele fundo "cênico". Só estrutura, o efeito tá no style.css.

nav-time-container
- caixinha fixa no canto com o relógio. O id brasilia-clock é
  quem o clock.js atualiza.

card / form
- form#formCep com input#cep e o botão. Eu percebi que precisa
  do maxlength="9" porque o CEP formatado tem 8 números + 1
  hífen (o script formata 99999-999 enquanto você digita).
- p#mensagem é onde eu mostro erro/sucesso.

resultado (endereço)
- seção#resultado que começa com class="resultado oculto".
  O "oculto" é display:none; só mostro depois que a API
  respondeu. Cada campo (logradouro, bairro, cidade, estado,
  ddd) tem um id que o script preenche.

LOCALIZAÇÃO (o mapa)
====================
<div class="mapa-container">
  <h2>Localização</h2>
  <div id="mapa" role="region" aria-label="Mapa da localização do CEP"></div>
  <p id="mapa-mensagem" aria-live="polite"></p>
</div>

- A div#mapa é onde o Leaflet vai desenhar o mapa. Ela nasce
  VAZIA e sem tamanho no HTML — quem dá altura é o CSS (320px) e
  quem desenha dentro é o JS.
- role="region" e aria-live são detalhes de acessibilidade (pra
  leitor de tela). Pequenas coisas que contam ponto.
- p#mapa-mensagem é onde eu mostro "Buscando localização..." ou
  um erro, no mesmo esquema do p#mensagem do form.

CLIMA (a parte que eu caprichei)
================================
div#wf-main-temp
- É o card que mostra temperatura/ícone/descrição.

Dentro dele eu coloquei 5 <video>:
  #wf-temp-video           -> nublado
  #wf-temp-video-chuva     -> chuva leve
  #wf-temp-video-ceu-limpo -> céu limpo
  #wf-temp-video-poucas    -> poucas nuvens
  #wf-temp-video-pancadas  -> pancadas de chuva

- Todos com autoplay muted loop playsinline.
- O muted é obrigatório pro navegador deixar tocar sozinho
  (senão ele bloqueia).
- Os 5 ficam escondidos (display:none no CSS) e o script mostra
  só o certo.
- Decisão: deixei todos os <video> no HTML em vez de criar por
  JS. Vantagem: é simples e já fica "pré-carregado" no DOM.
  Desvantagem: carrega várias fontes de vídeo de cara (mais peso
  no carregamento inicial). Mas pra esse caso valeu, o projeto é
  pequeno.

wf-extra-stats
- 4 cards: temp máx, mín, umidade e vento. Cada um com um ícone
  Font Awesome e um id de valor (wf-temp-max, -min, -humidity-val,
  -wind-val).
