=========================================================
MEU PROJETO - VISÃO GERAL
=========================================================

Projeto da matéria de Computação em Nuvem. A ideia é um site
que consulta CEP e mostra o clima da cidade, usando duas APIs
que ficam na nuvem:

- ViaCEP: dado o CEP, devolve o endereço completo.
- OpenWeatherMap: dado o nome da cidade, devolve o clima atual.

Além dos dados, eu coloquei vídeos de fundo que trocam
conforme o clima (nublado, chuva, sol, etc.) - foi a parte
mais legal de fazer porque eu tive que usar o código do clima
pra decidir qual vídeo mostrar.

ARQUIVOS
========
- index.html ........ página principal (form + resultado)
- style.css ......... visual da página principal
- script.js ......... consumir as APIs + lógica dos vídeos
- loading.html ...... splash screen de entrada
- loading.css ....... visual do loading
- clock.js .......... relógio de Brasília
- video/ ............ os vídeos de cada clima

FLUXO
=====
1. Primeiro acesso: cai no loading (animação GSAP).
2. Usa sessionStorage pra não repetir o loading na mesma sessão.
3. Navegou pro index: usuário digita o CEP.
4. script.js chama a ViaCEP -> preenche o endereço.
5. com a cidade, chama a OpenWeatherMap -> preenche o clima.
6. pelo código/descrição do clima, mostra o vídeo certo.
